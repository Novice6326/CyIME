# 文涛的 CyIME 定制版本

本仓库用于验证 CyIME 上游项目的 GitHub Actions 云编译，并在确认原版构建成功后开发定制功能。

## 已确定的定制需求
- 简洁实用的键盘外观。
- 中文 26 键拼音、九宫格、英文输入。
- 手写识别必须支持离线使用。
- 语音识别自动切换：优先联网，网络不可用时使用离线识别；在线服务须明确配置并提供隐私说明。
- 本地词库联想，并评估可选的联网增强。
- 逐字输入工具：读取剪贴板内容后逐字提交，支持开始、暂停/继续、停止。
- 退格轻点删除一个字，长按清空当前输入框。

遵守上游 GPL-3.0 及第三方模型、词库各自的许可和署名要求。

## 云编译验证
仓库所有者已启用 GitHub Actions；本次提交用于触发上游构建工作流，先验证原版构建环境。
